# 一览

macOS 菜单栏小工具：分应用音量控制 + 系统状态（CPU / 内存 / 磁盘 / 网络 / 电池与实时功率）+ AI 用量（Claude Code、Codex）+ 保持唤醒（类似 Amphetamine）。

- 左键：弹出面板（音量 / 状态 / AI 三页）
- Option + 左键：一键开关「保持唤醒」（无限期），开启时菜单栏最左侧显示咖啡杯
- 右键：选择菜单栏显示项、保持唤醒时长（15 分钟～8 小时 / 无限期，可选允许屏幕关闭、合盖也保持唤醒）、登录时启动、退出

## 构建

```bash
./build.sh
cp -R "build/一览.app" /Applications/
```

需要 macOS 14.2+、Swift 5.9+。Claude 套餐百分比读取钥匙串中 Claude Code 的登录（只读，不刷新令牌）。

合盖保持唤醒：首次开启时输入一次管理员密码，安装 `/etc/sudoers.d/yilan-pmset`（只允许当前用户免密执行 `pmset -a disablesleep 0/1`）。会话结束、退出或下次启动（崩溃恢复）时自动关回；用电池且电量低于 15% 自动停止。右键菜单「移除合盖辅助…」可卸载。
